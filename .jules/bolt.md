## 2024-08-05 - O(N) Bottleneck with JSON.stringify in Prometheus Metrics Middleware
**Learning:** The Prometheus metrics middleware was storing stateful, high-cardinality data (HTTP request duration histograms and counters) in Arrays. For every HTTP request, it searched these arrays linearly using `array.find()`, and even worse, it called `JSON.stringify()` on every item's labels during the comparison. This created a massive O(N) computational bottleneck on the main thread that grew with the number of unique routes and status codes.
**Action:** When tracking high-cardinality metrics in Node.js, always use `Map` objects with unique string keys for O(1) lookups instead of Arrays. Never use `JSON.stringify()` inside an `array.find()` loop, especially not in request-blocking middleware.
